Installation Android

📱 Installer comme App 📦 Télécharger APK
1 Méthode recommandée : Cliquez sur "Installer comme App" ci-dessus
2 Alternative : Téléchargez l'APK, activez "Sources inconnues" dans les paramètres, puis installez
3 Accès : L'application apparaîtra sur votre écran d'accueil

Installation iOS (iPhone/iPad)

1 Ouvrez cette page dans Safari (pas Chrome)
2 Appuyez sur le bouton Partager (carré avec flèche vers le haut)
3 Sélectionnez "Ajouter à l'écran d'accueil"
4 Confirmez en appuyant sur "Ajouter"
5 L'icône apparaîtra sur votre écran d'accueil

Installation Windows

1 Ouvrez cette page dans Microsoft Edge ou Chrome
2 Cliquez sur l'icône "Installer l'application" dans la barre d'adresse
3 Ou utilisez le menu ⋯ > Applications > Installer cette site en tant qu'application
4 L'application sera disponible dans le menu Démarrer

Installation Web (PWA)

🔗 Ouvrir dans le navigateur
1 Cliquez sur "Installer maintenant" ou recherchez l'icône d'installation dans votre navigateur
2 L'application fonctionnera hors ligne après installation
3 Accès rapide depuis le bureau ou menu d'applications

Résolution de problèmes

L'option d'installation n'apparaît pas :

Assurez-vous d'utiliser un navigateur compatible et que JavaScript est activé.

Erreur lors de l'installation :

Redémarrez votre navigateur et réessayez. Vérifiez votre connexion internet.

Application lente :

Fermez et rouvrez l'application. Vérifiez l'espace de stockage disponible.
